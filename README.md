# 有道翻译 · Alfred Workflow

在 Alfred 里输入 `yd`，就能查单词、翻译句子、听发音，也能把结果直接粘贴到正在编辑的内容中。

延续上一版以查词为主的使用方式，4.1.0 修复了中译英、日语和韩语释义，以及句子翻译等功能。

## 下载与安装

**[下载最新版 Workflow](https://github.com/whyliam/whyliam.workflows.youdao/releases/latest)**，在页面的 **Assets** 中下载 `whyliam.workflows.youdao.alfredworkflow`，双击导入 Alfred。

需要已解锁 Workflow 功能的 Alfred（Powerpack），以及 Python 3。安装后无需配置有道账号、API Key 或 Cookie。

## 开始使用

唤出 Alfred，输入 `yd`，按空格，再输入想查询的内容：

| 想做什么 | 输入示例 |
| --- | --- |
| 英译中、查英文单词 | `yd hello` |
| 中译英 | `yd 你好` |
| 翻译英文短语 | `yd How are you?` |
| 翻译句子 | `yd 今天下午我们一起去公园散步。` |
| 查日语释义 | `yd こんにちは` |
| 查韩语释义 | `yd 안녕하세요` |
| 查看最近查询 | `yd *` |

结果中会显示释义、翻译，以及有道提供的音标或拼音。用方向键选择需要的那一项，再按下面的快捷键操作。

## 对查询结果进行操作

| 快捷键 | 功能 |
| --- | --- |
| **回车 ↩** | 复制选中的释义或译文 |
| **Command ⌘ + 回车** | 将选中的结果直接粘贴到当前输入位置 |
| **Control ⌃ + 回车** | 打开有道词典网页，查看详细释义和例句 |
| **Shift ⇧ + 回车** | 朗读查询的原文 |

发音使用 macOS 本机语音。英文、中文、日语和韩语会自动选择对应语言的声音。

即使没有查到结果，或网络查询失败，也可以按 **Control ⌃ + 回车** 到有道网页继续查询。

### 查看历史查询

输入 `yd *`，显示最近 9 条释义。选择后，同样可以复制、粘贴、打开网页或朗读原文。

历史记录保存在本机，最多保留 200 条释义；同一查询的不同释义可能分别占一条。

### 选中文字，快捷查询

如果经常在阅读时查词，可以在 Alfred 的 **Workflows → Youdao** 中设置 Hotkey：

1. 打开 Hotkey 节点，设置自己习惯的快捷键，并将传入内容设为选中的文字。
2. 确认 Hotkey 已连接到 `yd` 的 Script Filter 输入节点；没有连线时，先连接这两个节点。
3. 保存后，在其他应用中选中文字，按刚才设置的快捷键即可查询。

快捷键需要自行设置，安装包没有预设“双击 Option”。

## 常见问题

**输入 `yd` 后没有结果？**

先确认 Workflow 已导入并启用，再试试 `yd hello`。本工具需要联网；遇到“查询失败”时可稍后重试，或按 Control + 回车打开网页。

如果 Alfred 调试窗口提示找不到 `/usr/bin/python3`，需要安装 Apple Command Line Tools，或将 Workflow 脚本中的 Python 路径改为本机 Python 3 的绝对路径。

**复制成功，但不能直接粘贴？**

确认目标应用处于可输入状态，并在 macOS 系统设置的“隐私与安全性 → 辅助功能”中允许 Alfred 控制电脑。

**没有朗读声音？**

先检查系统音量，再到 macOS 的语音设置中确认相应语言的声音已下载。朗读使用本机语音，音色可能与有道网页不同。

**还能同步到有道在线单词本吗？**

目前不支持。旧版的 Alt + 回车同步操作已停用，不需要填写 Cookie。

**查询内容会保存或发送到哪里？**

查询原文会发送给有道获取结果；历史释义保存在本机，不会随安装包分享。有道网站接口可能调整或限流，具体译文以实际返回为准。
